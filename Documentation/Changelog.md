# Changelog — SN Editor

## 1.0.0 — Initial Codester release

- Image editor: layers, text, shapes, brand kit, uploads, export
- Video editor: multi-track timeline, animate, transitions, filters, audio
- Login / register with demo accounts (`user@gmail.com`, `admin@gmail.com`)
- Admin panel: brand name + logo, admin password, Stripe keys, Stripe plans, user list
- Premium gating on selected image and video tools (demo user has full premium)
- Canva-inspired UX: contextual toolbar, junction transitions, animate phases
- Monorepo: `@sn-editor/*` packages + Next.js web app
- Documentation set for Codester (Installation, Usage, Support)
- Default product brand: **SN Editor**
