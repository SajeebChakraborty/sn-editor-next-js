FULL DESCRIPTION:

SN Editor is a full-stack web editor for creating social graphics and short videos in the browser. Buyers receive complete source code with documentation.

Live demo: https://sn-editor.sajeebit.com/

Key features
• Image editor with layers, text presets, shapes, brand kit, uploads, filters, and export (PNG / JPG / PDF)
• Video editor with timeline, drag-and-drop clips, transitions, Animate presets, filters, audio, and export
• Login and register — users are saved in MongoDB or a local JSON database
• Admin panel — white-label brand name and logo, change admin password, add many Stripe plans, update Stripe keys, manage users
• Premium subscriptions via Stripe Checkout (demo user already has all premium tools unlocked)
• Clean light / dark UI with floating clip toolbar and circular play controls
• Monorepo architecture (pnpm + Turborepo) — easy to extend
• TypeScript + React + Next.js 15 + Konva
